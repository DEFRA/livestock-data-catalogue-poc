Accessibility statement for the Livestock Data Catalogue prototype

This prototype is run by the Department for Environment, Food and Rural Affairs (Defra). It is for research, and its data is made up.

We want as many people as possible to be able to use it. For example, you should be able to:

  • use it without JavaScript
  • zoom in up to 400% without the text spilling off the screen
  • move around it using just a keyboard
  • use it with a screen reader

How accessible this prototype is

We build every page with the GOV.UK Design System, and aim to meet the Web Content Accessibility Guidelines (WCAG) version 2.2 at AA level.

This prototype is partially compliant with the Web Content Accessibility Guidelines version 2.2 AA standard, because of the known issue listed below.

We check every page with automated tests. We have not yet finished checking it by hand or with assistive technologies, and it has not had an accessibility audit.

Reporting accessibility problems

If you find a problem, report it.

Known issues

Keywords in Welsh, such as gwartheg, are not marked as Welsh, so screen readers may read them as English. This fails WCAG 2.2 success criterion 3.1.2 (language of parts). The catalogue does not yet record which language a keyword is in, and we have asked for it to be added.

We will list any other problems we find here.

Preparation of this statement

This statement was prepared on 4 November 2026. It was last reviewed on 5 November 2026.
